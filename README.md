## 🧰 Featured Production Toolsets

### 1. [Verify API Suite](https://verify.drain54.my.id)
Unified MCP gateway for autonomous agents with built-in micropayments (x402 / Base USDC) & SSRF guards.
* **`read_web_page`**: Clean DOM-to-Markdown parser built for low-latency RAG pipelines.
* **`fetch_stealth_web`**: Headless browser extraction with anti-bot evasion.
* **`extract_json_from_web`**: Deterministic schema-driven JSON extraction from unstructured web pages.
* **`solve_captcha`**: Turnstile, hCaptcha, and reCAPTCHA solver integration.
* **Official Registry:** `io.github.drain54/verify-api`
